# House of Titaura 🇳🇵

A production-grade e-commerce platform for authentic Nepali titaura, built with ASP.NET Core and React/TypeScript, featuring Clean Architecture, local payment gateways, automated testing, and Azure CI/CD.

## Tech Stack

- **Frontend:** React.js, TypeScript
- **Backend:** ASP.NET Core Web API (C#)
- **Architecture:** Clean Architecture
- **Database:** SQL Server
- **Payments:** Nepali payment gateways (eSewa, Khalti)
- **Testing:** xUnit, integration testing, frontend testing
- **DevOps:** GitHub Actions, CI/CD
- **Cloud:** Microsoft Azure
- **Version Control:** Git & GitHub

## 🚧 In Progress

This project is currently under active development. Core features, payment gateway integrations, automated testing, and Azure deployment pipelines are being implemented.
